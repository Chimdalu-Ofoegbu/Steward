# Steward x402 — selling the decision journal to other agents

Steward puts its **on-chain-attested decision journal behind an x402 paywall**: another
agent pays a tiny **WCSPR** micropayment to read a decision, settled **gas-free** by
Casper's hosted facilitator. This makes Steward a **seller** in the machine economy — even
its *outputs* are transacted and auditable on-chain — using Casper's flagship x402 primitive
on the exact `casper-js-sdk` v5 stack the agent already runs.

## Flow (the libraries handle the headers)
```
1. GET /journal/:hash
2. 402 Payment Required   + PAYMENT-REQUIRED header
3. buyer signs an EIP-712 authorization (WCSPR, "exact" scheme)
4. GET /journal/:hash     + PAYMENT-SIGNATURE header
5. seller -> facilitator  /verify then /settle
6. facilitator -> chain   WCSPR transfer_with_authorization (facilitator pays the CSPR gas)
7. 200 OK                 + PAYMENT-RESPONSE header (settlement result)
```
- Network `casper:casper-test`, scheme `exact`, asset **WCSPR** (a CEP-18 token) package
  `3d80df21…847c1e`, 9 decimals. The payment asset is a token, **not native CSPR**.
- Facilitator: `https://x402-facilitator.cspr.cloud` (hosted; pays the settlement gas).

## Files
- `agent/sidecar/x402_journal_server.mjs` — the **seller** (Express + `@x402/express` + `ExactCasperScheme`).
- `agent/sidecar/x402_client_demo.mjs` — a headless **buyer** that pays and reads (the proof).

## Setup
1. **Deps** — already installed in `agent/sidecar/` (`@make-software/casper-x402`, `@x402/{core,express,fetch}`, `@casper-ecosystem/casper-eip-712`, `express`).
2. **Get a CSPR.cloud API key** — sign up at **console.cspr.build / cspr.cloud**, create an access key, and put it in `agent/.env` as `FACILITATOR_API_KEY=…`. *This is the one required action* — it's the facilitator auth and the gas-sponsored path.
3. **Set the payee** — `PAYEE_ADDRESS=<account that receives the WCSPR>` in `agent/.env` (e.g. Steward's agent account).
4. **Fund the buyer with WCSPR** — the buyer key needs testnet **WCSPR**: get testnet CSPR from the faucet (`testnet.cspr.live/tools/faucet`), then **wrap CSPR → WCSPR 1:1** (CSPR.trade's Wrap tool, or the WCSPR contract). Point the buyer at that key with `BUYER_PEM=…`.

## Run (end-to-end — needs the key + WCSPR)
```bash
# Seller (Node 20+ loads agent/.env via --env-file):
node --env-file=agent/.env agent/sidecar/x402_journal_server.mjs

# Buyer, in another shell — pays WCSPR for the epoch-5 decision:
BUYER_PEM=./secrets/buyer_key.pem \
  node --env-file=agent/.env agent/sidecar/x402_client_demo.mjs
```
On success the buyer prints a `PAYMENT-RESPONSE` header — a real WCSPR
`transfer_with_authorization` settled on testnet, **verifiable on https://testnet.cspr.live**.

## Status
**Scaffolded and verified up to the auth boundary.** The server builds, registers the Casper
`exact` scheme, and reaches the hosted facilitator (which correctly 401s an invalid key).
Without a key the server still runs: free `GET /journal` discovery works and the paid route
returns `503` (never a free leak). The real 402 → settle path just needs your CSPR.cloud key
plus a WCSPR-funded buyer (setup steps 2–4).
